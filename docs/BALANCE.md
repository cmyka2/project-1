# Balance report

Generated by `tests/balance/Balance.spec.luau` from the live config. Regenerate after tuning:

```
BALANCE_WRITE=1 lune run tests/run tests/balance/Balance.spec.luau
```

These are model estimates, not playtest data. The simulated player uses no skills, ascension, equipment, potions,
events, stars, monster levels or battle rewards, so real players should progress faster. Treat the numbers as
the pacing *shape* and re-check them against analytics after launch.

## Offline earnings

Offline income = online rate (permanent multipliers only) × min(time away, 2 h base cap, up to 12 h with upgrades) × 50% efficiency (up to 100%). Absences under 60 s pay nothing.
